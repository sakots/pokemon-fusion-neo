# 試作の操作画面

## 対象と画面構成

頭・体の素材を用意した第1世代151種類を選択できます。初期選択は頭がNo.0001フシギダネ、体がNo.0004ヒトカゲです。全1025種類の一覧は準備済みですが、部位素材のない種はこの画面の選択肢に含めません。151種類の試作で、形と配色を調整中であることを表示します。

画面は、頭と体それぞれの選択欄、両方のランダム選択と交換ボタン、現在の合体結果で構成しています。選択欄には選択中の番号・日本語名・元画像、検索欄、候補のプルダウンを置いています。

## 検索と選択

検索語は頭と体で別々に持ちます。前後の空白を除き、NFKCで正規化し、カタカナをひらがなに揃えて名前の部分一致を調べます。数字だけの検索語は図鑑番号の完全一致とし、`1`、`0001`、`０００１`は同じ番号を指します。

空の検索語では151種類すべてを番号順にプルダウンへ表示します。検索欄で絞り込み、プルダウンから選ぶと、その側の選択を更新します。検索で絞っただけでは選択を変えません。現在の選択が検索結果に含まれない場合は、選択中の種を選び直せない項目として残し、プルダウンの表示と現在の選択を一致させます。検索結果が0件の場合は「該当するポケモンがありません」と表示してプルダウンを無効にし、現在の選択と合体結果は維持します。検索語を消すと全候補に戻ります。

## ランダムと交換

頭だけ、体だけ、両方のランダム選択を用意します。検索語に関係なく、選択可能な151種類すべてから選びます。同じ種同士や、現在と同じ選択になる場合も許します。乱数は0以上1未満を前提とし、テストでは先頭と末尾の選択を確認します。

交換は頭と体の番号だけを入れ替えます。検索語はその欄に残し、検索結果に現在の選択が含まれない場合も、選択中の表示は維持します。2回交換すると元の選択に戻ります。

## 合体結果と状態表示

選択を更新すると合体名と画像を再計算します。前の画像は次の画面描画前に消し、読み込み中と表示します。処理中も検索・選択・交換を操作できます。古い処理の成功や失敗で、最後の選択の表示を上書きしません。

画像・読み込み中の表示・失敗時の再試行は、同じ高さ128pxの画像枠内に表示します。読み込み開始・完了・失敗で結果カードの高さや合体名・配色切り替えの位置を変えません。

このサイズ固定は実ブラウザの幅360pxと1280pxで確認しました。素材取得を保留して読み込み中を測定し、完了・取得失敗・再試行・交換後の再読み込みでも、結果カードの寸法と合体名・配色切り替えの位置が一致しました。失敗表示と再試行ボタンも画像枠内に収まり、横方向のはみ出しはありませんでした。

画像の読み込み失敗は結果欄に表示し、再試行ボタンを用意します。同種同士は元の画像と名前を使います。描画規則と素材の品質上の制約は[合成の試作](fusion-prototype.md)を参照してください。

「体の色を頭に合わせる」は初期状態でオンです。オフにすると体の元の配色を表示します。設定は検索・選択・交換でも維持します。規則と比較画像は[配色の試作](color-matching.md)を参照してください。

## 操作と表示の検証

検索欄とプルダウンには頭・体を区別できるラベルを付け、ランダム選択と交換にはbuttonを使います。プルダウンは標準のselectを使い、Tabキーで移動し、矢印キーで候補を選べます。検索件数をプルダウンの説明として関連付け、検索件数と読み込み状態は読み上げ可能にします。

実装前に、検索の正規化・番号検索・0件、ランダムの範囲、初期選択、候補選択、交換、検索中のランダム、同種同士のテストを書き、失敗を確認してから実装しました。古い処理の成功と失敗を反映しないこともテストで確認しています。画像そのものは実ブラウザで確認します。

幅360pxと1280pxで、通常・0件・処理中・失敗時の表示、横方向のはみ出し、文字のコントラスト、キーボードのフォーカスと選択を確認します。

## 確認結果

操作画面を追加した段階では、自動テスト51件、型検査、ビルド、全種の元データ・元画像と試作の部位素材の検証が成功しました。配色の切り替えを追加した後の確認結果は[配色の試作](color-matching.md#最初の6種類での確認結果と残る課題)に記載しています。

Edgeで幅360pxと1280pxの操作画面を確認しました。

| 項目 | 結果 |
| --- | --- |
| 初期選択 | フシギダネの頭とヒトカゲの体でフシギカゲを表示した |
| 検索 | 半角カナと全角番号で候補を選択できた。0件でも選択と現在の画像を保持した |
| 交換 | 2回交換して元の組み合わせに戻り、検索語も維持した |
| ランダム | 検索語に関係なく頭・体・両方を選択できた。乱数を固定し、先頭と末尾の選択も確認した |
| 同種同士 | ピカチュウ同士の結果が元画像のピクセルと一致した |
| キーボード（旧ボタン式） | 検索欄からTabキーで候補へ移動し、Enterキーで選択できた。フォーカス表示も確認した |
| 画像の失敗 | 素材取得を意図的に遮断して失敗表示を確認し、解除後の再試行で画像を表示できた |
| 処理中の連続操作 | 通信に600msの遅延を入れて選択・交換・再選択を行い、最後の組み合わせだけが表示された。前の画像は処理中に消えた |
| 表示 | 通常・0件・処理中・失敗時に横方向のはみ出しはなかった。通常と失敗時の文字コントラスト比は最小約6.1対1だった |
| 実行エラー | アプリケーションのJavaScript例外はなかった |

プルダウンへの変更時は、自動テスト85件、型検査、ビルドが成功しました。Chromiumの幅360pxと1280pxで、半角カナ・全角番号の絞り込みと選択、0件での選択維持、検索を消したときの151候補への復帰、交換・ランダム後の表示同期を確認しました。Tabキーで検索欄からプルダウンへ移動し、矢印キーで選択と合体結果を更新できました。横方向のはみ出しとアプリケーションのJavaScript例外はありませんでした。

全1025種類の部位・配色の定義と品質調整は未完了です。Firefoxは環境側の制約で未確認のため、リリース前に確認が必要です。

現在の第1世代151種類の素材と確認結果は[第1世代のサンプル](generation-one.md)を参照してください。
