# 構成と開発・リリース方針

現行の要求とシナリオは[OpenSpecの仕様一覧](README.md#現行仕様openspec)、変更提案の管理方法は[OpenSpecの運用](openspec.md)を参照してください。この資料は技術構成と開発・リリース時の確認方針をまとめます。旧実装計画に混在していた機能仕様はOpenSpecへ整理し、完了済みの開発段階を今後の作業一覧としては扱いません。

全国図鑑No.0001〜1025の基本形を扱います。全種の元画像・部位・配色を整備済みですが、全1,050,625通りの形・配色の品質完成を保証するものではありません。過去の実装・検証の根拠は[調査・試作・世代別の記録](README.md#調査試作世代別の検証記録)に残します。

## 技術構成

| 用途 | 使用するもの・方針 |
| --- | --- |
| 画面 | React・TypeScript |
| パッケージ管理 | pnpm。使用版はpackage.jsonのpackageManager、依存関係はpnpm-lock.yamlに記録する |
| 開発サーバー・ビルド | Vite |
| 状態管理 | Reactのstateで選択番号、検索語、配色設定、読み込み状態を管理する |
| 表示の調整 | CSS。配色、余白、文字サイズを共通のCSS変数で定義する |
| 合成 | Canvas 2D。座標計算と名前生成は画面から独立したTypeScriptの関数にする |
| 自動テスト | Vitest、React Testing Library |
| 配信 | ビルドした静的ファイルと、同じ配信元に置くデータ・画像 |
| 仕様・変更管理 | OpenSpecの標準spec-drivenスキーマ |

起動環境・コマンドは[開発環境](development.md)に記載します。閲覧時の合体に外部の画像生成サービスは使いません。部位・配色のJSONはJavaScriptに埋め込まず、独立したアセットとして読み込みます。

## 開発手順

1. [OpenSpecの運用](openspec.md)に従い、関連する仕様・手順を先に更新します。1つの変更で扱う機能追加・修正は1つに絞ります。
2. 動作変更では、期待する振る舞いのテストを書き、失敗を確認してから最小実装します。資料だけの変更は本文・リンク・設定と仕様の読み込みを確認します。
3. 変更した画面・コマンドを実際に動かします。Canvasの正しさは描画APIを置き換えたテストだけでは判断せず、実ブラウザでも確認します。
4. 不要なコードと資料の矛盾を取り除き、ユーザーの無関係な変更は保持します。不要な後方互換やデータ移行コードは追加しません。
5. 関連資料とREADME.md・changelog.mdの更新履歴を揃え、完了した変更をアーカイブします。コミットは行いません。

データ取得と検証は[データ準備](data-preparation.md)、部位・接続・補完・配色の編集は[部位定義の編集ツール](mask-editor.md)を参照してください。

## テスト方針

| 対象 | 確認する振る舞い |
| --- | --- |
| データ・素材 | 1〜1025の網羅、不足・重複・範囲外・素材欠落、不正な接続点・配色の拒否、定義と生成物の一致 |
| 名前・検索 | 前半と後半の連結、同種同士の元名、かな・半角の正規化、番号検索、空検索、0件 |
| ランダム・交換 | 選択範囲の先頭・末尾、検索語に依存しない選択、2回の交換で元の選択に戻ること |
| 合成・配色 | 接続と出力範囲、描画順、同種の元画像保持、変換対象と透過・保護領域、元データを変更しないこと |
| 画面 | 検索からの選択、交換、処理中、失敗と再試行、古い処理を反映しないこと、結果枠の安定 |
| 部位編集 | 入力中と確定後の状態、不正入力での保存停止、失敗した取込で既存定義を保持すること |

正常系だけでなく、境界・エラー・連続操作を確認します。過去のテスト件数や確認表は当時の実施記録であり、今回の検証の代わりにはしません。

## リリース前の確認

[開発環境の自動確認](development.md#自動確認)にあるテスト・型検査・データ検証・素材検証・ビルド・差分チェックに加え、`openspec validate --all --strict --no-interactive`を実行します。新規ファイルも空白・リンクの検査対象にします。配信確認は`pnpm preview`で行い、JSONと画像を含む`dist`全体を配置します。

このプロジェクトでのテーマ診断は、画面の配色と表示・操作の確認です。幅360pxと1280pxで、横方向のはみ出し、選択欄と結果の読みやすさ、文字と背景のコントラスト、フォーカス表示、ドット絵の輪郭を確認します。検索0件、処理中、失敗時も同じ条件で確認します。Chrome系とFirefox、モバイル相当の画面で動作を確認します。

全種の素材検証に加え、各種について頭として使う例と体として使う例を確認し、形状ごとの代表的な組み合わせは目視で点検します。この確認は約105万通りすべての画質保証ではないため、確認した組み合わせと未解決の制約を記録します。素材不足や未対応の種が残る場合は、1025種類対応としてリリースしません。Firefoxなど未確認の環境は、確認済みとして扱いません。

更新履歴はREADME.mdとchangelog.mdに同じ内容を、`### [YYYY/MM/DD] vx.x.x`と箇条書きの形式で追記します。
