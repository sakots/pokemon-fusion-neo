# ポケモンデータの準備

## 対象と取得元

全国図鑑No.0001〜1025の日本語名、世代、基本形に対応するポケモンIDと元画像を準備します。合体名の分割、頭・体の素材と接続点は、この段階では追加しません。

種のデータは[PokéAPIの公開CSV](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv)を使います。APIと同じ公開データをまとめて取得し、1025件の種別APIリクエストを避けます。

| ファイル | 参照する情報 |
| --- | --- |
| languages.csv | ja-hrktとjaの言語ID |
| pokemon_species.csv | 全国図鑑番号とgeneration_id |
| pokemon_species_names.csv | 言語別の種名。ja-hrktを優先し、なければja |
| pokemon.csv | species_idに対応するis_default=1のポケモンID |

データの版は`c80757193bd0889054e36f4209762360bdaa4b95`、画像の版は`0dc105d5b12416932f29b594078282ab4be045f5`に固定します。取得日時と版は生成するレポートにも記録します。

画像は[PokeAPI/sprites](https://github.com/PokeAPI/sprites)の`sprites/pokemon/{基本形のポケモンID}.png`を候補とします。第5世代風のドット絵系列ですが、公式ゲームの素材とコミュニティ制作の素材を含むため、合成用の画風と部位の品質は試作で別途確認します。

## 生成ファイルとコマンド

`pnpm import:data`と`pnpm validate:data`を実装しました。次の手順で使います。

```bash
pnpm import:data
pnpm validate:data
```

`import:data`は固定した版のCSVを.cache/pokeapiへ保存し、最大6件ずつ元画像を取得します。保存済みのCSVと画像は再利用します。取得にはタイムアウトを設け、取得失敗を成功として扱いません。

一覧はsrc/data/pokemon.json、画像はpublic/assets/pokemon/{全国図鑑番号}.pngに保存します。画像URLはアプリの配信元を使い、通常の閲覧時には外部APIやGitHubにアクセスしません。src/data/import-report.jsonには取得元、版、取得日時、件数、画像寸法の分布と不足・不正の一覧を記録します。

種データまたは画像の検証に失敗した場合は、番号と理由を報告し、終了コード1で終了します。一覧はすべての元画像が検証を通ってから書き込みます。取得できた画像とキャッシュは残し、再実行時に再利用します。

`validate:data`はネットワークを使わず、保存された一覧と1025枚の元画像を検証します。部位素材の検証は合成の実装段階で追加します。このコマンドの成功だけで、1025種類の合体対応が完了したとはしません。

## 検証条件

- 全国図鑑番号1〜1025が各1件あり、欠番、重複、範囲外、整数以外の番号がないこと。
- 日本語名が空でなく、世代が1〜9の整数であること。
- 各種に基本形が1件あり、そのポケモンIDが正の整数であること。種の番号から画像のIDを推測しないこと。
- 日本語名の取得元に重複がないこと。番号1026以降や姿違いを対象数に含めないこと。
- 画像パスが対応する図鑑番号のローカルパスであること。
- PNGが復号でき、幅・高さが正で、透過部分と可視部分があること。画像の寸法はレポートに記録すること。

テストでは、名前の優先順位、種の番号と基本形IDが異なる場合、基本形の不足・重複、欠番・範囲外、壊れたPNG、全透過画像と透過のない画像を確認します。実データの検証はコマンドで行い、1025種類の内容をテスト内に複製しません。

## 素材の出典

[spritesのLICENCE.txt](https://github.com/PokeAPI/sprites/blob/0dc105d5b12416932f29b594078282ab4be045f5/LICENCE.txt)は、リポジトリのCC0表記と画像のThe Pokémon Companyへの著作権帰属を併記しています。CC0表記だけを画像に関するすべての権利の放棄として扱いません。元の表記をpublic/assets/pokemon/LICENCE.txtに保存します。

制作協力の出典は[READMEのSpecial Thanks](https://github.com/PokeAPI/sprites/tree/0dc105d5b12416932f29b594078282ab4be045f5#special-thanks)を参照します。元画像の収集は合成の開発用素材を準備する段階です。
