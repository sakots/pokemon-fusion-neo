# 開発環境

## 前提と現在の段階

Node.js 26以上とpnpm 12.11.2を使います。package.jsonのpackageManagerとpnpm-lock.yamlで、使用するpnpmと依存パッケージを記録します。

開発基盤にはReact・TypeScript・Viteによる起動、VitestとReact Testing Libraryによる画面テスト、TypeScriptの型検査、静的ビルドを用意しています。1025種類の元データと元画像も準備済みです。現在の画面では第1〜第5世代の649種類から頭と体を選び、合成結果を表示します。名前・番号での検索、ランダム選択と交換に加え、皮膚色を頭に合わせる切り替えを操作できます。

以下のコマンドを実行できます。

## 起動

```bash
pnpm install --frozen-lockfile
pnpm dev
```

開発サーバーが出力したURLを開きます。

## 自動確認

```bash
pnpm test
pnpm typecheck
pnpm validate:data
pnpm validate:fusion
pnpm build
git diff --check
```

`pnpm test`は監視せずに終了します。開発中にテストを監視する場合は`pnpm test:watch`を使います。型検査は部位定義の編集ツール、アプリケーション、データ準備スクリプト、テスト、Viteの設定を対象とします。ビルドは型検査の後に行い、distへ出力します。

部位・配色情報の`src/data/fusion-parts.json`は、JavaScriptへ埋め込まず、Viteの`?url`で独立したJSONアセットとして出力します。起動時にそのURLから読み込み、取得中は状態表示、HTTPエラーやJSONの解析失敗時はエラー表示にします。取得に成功したデータを画面へ渡すため、選択・合成の処理はこれまでと同じ情報を使います。500KBのチャンク警告のしきい値は変更しません。配信時にはJavaScriptだけでなくJSONを含む`dist`全体を配置します。

この変更後は自動テスト85件、型検査、ビルドが成功し、JavaScriptは227.76kBでチャンクサイズ警告は出ませんでした。出力したJSONと元データのSHA-256は一致しました。ビルド済み画面の幅360pxと1280pxで、起動時の読み込み表示、151候補の表示、検索・選択・配色切り替え・交換を確認しました。JSON取得を意図的に503応答・不正なJSON・通信失敗にした場合はエラーを表示し、通常の配信に戻してページを再読み込みすると初期の合体結果を表示できました。

`pnpm validate:data`は、保存済みの一覧と1025枚の元画像をネットワークなしで検証します。再取得には`pnpm import:data`を使います。取得元とキャッシュの詳細は[データ準備](data-preparation.md)を参照してください。

`pnpm prepare:fusion`でマスク定義から試作の頭・体、接続情報と配色・変換対象のピクセルを生成し、`pnpm validate:fusion`で生成物と定義の一致を検証します。マスク、接続点や配色を変えた場合は、生成・検証の後にビルドします。詳しくは[画像合成の試作](fusion-prototype.md)と[配色の試作](color-matching.md)を参照してください。

## ブラウザでの確認

```bash
pnpm preview
```

ビルド済みの画面を確認します。開発基盤では、幅360pxと1280pxで見出しと準備状況が表示され、横方向にはみ出さないことを確認します。表示色は背景に対して読み取れるものを使い、日本語のページとして表示します。

全機能のテーマ診断とリリース条件は[実装仕様](implementation-plan.md#リリース前の確認)に従います。

Node.js v26.11.1、pnpm v12.11.2で確認しました。

| 確認項目 | 結果 |
| --- | --- |
| TDD | 未実装の画面で見出しのテストが失敗することを確認し、実装後に1件のテストが成功した |
| 型検査・ビルド | pnpm build内の型検査とViteのビルドが成功した |
| ロックファイル | pnpm install --frozen-lockfileが成功した |
| Edgeでの表示 | 幅360pxと1280pxで見出しと準備状況が表示され、日本語設定と横方向のはみ出しがないことを確認した |
