# 画像合成の試作

## 対象と確認すること

No.0001フシギダネ、0004ヒトカゲ、0025ピカチュウ、0023アーボ、0081コイル、0102タマタマを対象とします。通常の頭と体、蛇型、頭と体が一体の形、複数の頭を含む形について、部位の切り分けと接続を確認します。

この資料は、素材と左右を含む36通りを表示して合成規則を検証した段階の記録です。この段階では配色を変更していません。現在の画面は第1〜第4世代493種類から組み合わせを選ぶ[操作画面](selection-ui.md)で、試作であることを明記しています。[皮膚色の変換](color-matching.md)も切り替えられます。

## 素材の準備

元画像を目視し、各種に頭を切り出す多角形を定義します。ピクセルの中心が多角形の内側にある場合、そのピクセルを頭素材に残し、体素材では透明にします。体の補完は別の多角形と色で定義し、頭を除去してできた接続部を埋めます。補完を先に行い、その上に元画像の頭以外のピクセルを重ねます。

素材の可視範囲と接続点を含む領域に1ピクセルの余白を残し、残る透明な余白を除きます。接続点も切り出した素材の左上を原点とする座標へ変換します。元画像は変更しません。多角形、補完領域、接続点と接続幅をsrc/data/fusion-masks.jsonに保存し、`pnpm prepare:fusion`でpublic/assets/fusionへ頭・体のPNGを生成します。寸法と接続情報はsrc/data/fusion-parts.jsonに保存します。

合体名の分割は、試作対象の6種類について手動で設定しています。コイルは顔のある球体を頭、磁石と残る部分を体として扱い、タマタマは手前の卵1個を頭、残る卵を体として扱います。この切り分けが全形状に通用するとは仮定しません。

補完は試作のための単色の領域で、元画像と同じ質感を再現する処理ではありません。腕や装飾の前後関係、接続の輪郭は36通りを目視して評価します。

## 合成の規則

同種同士は元画像と同じ96×96ピクセルのCanvasへ画像をそのまま描画し、元の名前を使います。異なる種の場合は左の頭と右の体を使い、名前の前半と後半を連結します。

体の接続幅を頭の接続幅で割った倍率で頭を調整し、接続点が一致する位置へ配置します。両素材の範囲の和を求め、128×128ピクセルの出力領域と8ピクセルの余白に収めます。全体の縦横比を保ち、拡大できる場合は整数倍率で拡大します。体、頭の順に描き、CanvasのimageSmoothingEnabledをfalseにしてドット絵の輪郭を保ちます。

画像の読み込みに失敗した場合は、その組み合わせにエラーを表示します。部品がない種や不正な寸法・接続点は処理を失敗させ、元画像で代用しません。コンポーネントの終了後には古い処理の結果を反映しません。

## テストと素材検証

合成の試作段階で、次の動作のテストを書いてから実装しました。

- 小さなRGBA画像で、頭と体のピクセルが分かれ、補完と透明部分が保持され、元画像が変わらないこと。
- 接続幅の比、接続点の一致、出力領域への収まり、不正な寸法・接続点・接続幅の拒否。
- 同種同士の名前と、異なる種の合体名。
- 試作画面が6種類・36通りであることと、試作段階を伝えること。

`pnpm validate:fusion`で、マスク定義と生成した素材のピクセル・寸法・接続情報が一致することを検証します。頭・体のPNGに可視部分と透過部分があることも確認します。全1025種の元データ・元画像の検証は既存の`pnpm validate:data`で別に行います。

合成の試作段階の最終確認では、実際のブラウザで36通りを描画し、読み込み失敗とJavaScript例外がないこと、同種同士のピクセルが元画像と一致することを確認しました。幅360pxと1280pxで表示とフォーカスも確認しました。Canvasの呼び出しを置き換えたテストだけで合成画像の品質を判断しません。

接続の品質、補完の露出、タマタマの残る顔、コイルの磁石の位置など、目視で分かった制約はこの資料に追記します。全種対応や最終品質の完了とはしません。

## 試作の確認結果

合成の試作段階で、6種類の頭・体の12枚と接続情報を生成しました。切り出しと接続計算に加え、試作表示、読み込み失敗と再試行、古い描画結果を反映しない動作を自動テストで確認しました。この段階では既存のデータ検証を含む37件のテスト、型検査、ビルド、元データと部位素材の検証が成功しました。

Edgeで、幅360pxと1280pxの36通りを確認しました。同種同士6通りは元画像のピクセルと一致し、異種30通りは透過を維持して8ピクセルの余白内に収まりました。異種30通りそれぞれの頭と体が重なるピクセルで、頭が前に描かれることも確認しました。素材以外の色は発生せず、補間も無効です。通常時の読み込み失敗とJavaScript例外はありませんでした。頭素材1枚の取得を意図的に遮断し、該当する5通りの失敗表示と、解除後の再試行も確認しました。

横方向のはみ出しはなく、表示文字のコントラスト比は最小約6.1対1でした。Tabキーによるリンクのフォーカス表示も確認しました。

目視で残った課題は次のとおりです。

- 接続部の単色の補完が露出する箇所があり、陰影と輪郭の調整が必要です。
- タマタマの頭には隣の卵の端が混ざる箇所があります。体側には他の卵の顔が残ります。
- コイルの体は磁石と補完した球体の一部です。生物型の頭を付けた場合の自然さは別途評価が必要です。
- 各種の向きと頭の傾きは調整していません。胴体との角度が揃わない組み合わせがあります。
- この段階では配色を未調整としていました。同種同士の元画像と合成画像では、透明な余白と表示倍率も異なります。

接続規則の動作を確認できる試作段階です。全1025種類の部位対応と最終品質の評価は今後の作業です。Firefoxの確認もリリース前に必要です。
