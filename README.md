# pokemon-fusion-neo

[ポケナビのポケモンフュージョンジェネレーター](https://pknavi.com/pokemonfusiongenerator)を参考に、全国図鑑No.0001〜1025のポケモンを合体できる生成機を開発するプロジェクトです。

1025種類の日本語名・世代・基本形の対応と元画像を準備し、6種類の頭・体を組み合わせるCanvas合成を試作しました。名前・図鑑番号で検索し、ランダム選択や左右交換で組み合わせを変えられます。体の皮膚色を頭に合わせる切り替えもできます。全種の部位・配色の定義と品質調整は今後の作業です。部位の追加に使う開発用の編集画面と、検証付きのJSON取込コマンドも用意しています。

実装にはReact・TypeScriptを使い、パッケージ管理にはpnpmを使います。

## 更新履歴

### [2026/10/13] v0.1.0

- 元サイトの画像表示方式と確認できていない制作工程を資料に整理した。
- 1025種類に対応するための画像合成方式と段階的な開発方針を資料に追加した。
- 調査結果と実装方針をdocs内に分離し、READMEに資料へのリンクを追加した。
- React・TypeScript・pnpmを前提とした実装仕様、データ準備、テストとリリースの確認手順を資料に追加した。
- React・TypeScript・Viteの開発基盤と準備状況を表示する初期画面を追加した。
- pnpmで画面テスト、型検査、ビルドを実行できるようにした。
- 全国図鑑No.0001〜1025の日本語名・世代・基本形の対応と元画像を追加した。
- データ取得と、欠番・重複・元画像の不足や不正を検証するコマンドを追加した。
- 6種類の頭・体の素材生成と接続情報の検証機能を追加した。
- Canvasで頭と体を合成し、36通りの試作画像を表示する機能を追加した。
- 試作対象を名前・図鑑番号で検索し、頭と体を選択する機能を追加した。
- 頭・体・両方のランダム選択と、頭と体を交換する機能を追加した。
- 輪郭や装飾の保護領域を保ち、体の皮膚色を頭の配色に合わせる機能を追加した。
- 配色変換の切り替えと、配色・変換対象ピクセルの検証機能を追加した。
- 元画像を見ながら部位・接続点・配色を指定し、JSONを保存する開発用の編集画面を追加した。
- 部位定義をJSONにまとめ、元画像との整合性を検証してから取り込むコマンドを追加した。
- 部位定義の編集画面に、頭の多角形の最後の点を1つ削除する機能を追加した。
