# pokemon-fusion-neo

[ポケナビのポケモンフュージョンジェネレーター](https://pknavi.com/pokemonfusiongenerator)を参考に、全国図鑑No.0001〜1025のポケモンを合体できる生成機を開発するプロジェクトです。

第1〜第9世代の全1025種類に、日本語名・基本形の対応・元画像・頭と体の部位・配色を定義し、Canvasで組み合わせる試作を実装しました。名前・図鑑番号で検索し、ランダム選択や左右交換で組み合わせを変えられます。体の皮膚色を頭に合わせる切り替えもできます。全種を選択できますが、全組み合わせの形と配色は引き続き調整中です。部位の調整に使う開発用の編集画面と、検証付きのJSON取込コマンドも用意しています。

実装にはReact・TypeScriptを使い、パッケージ管理にはpnpmを使います。
